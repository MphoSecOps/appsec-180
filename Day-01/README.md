## What I Learned

### What is AppSec?
Application Security is the practice of protecting
software applications from vulnerabilities and attacks
throughout the software development lifecycle.

### CIA Triad

Confidentiality:
Only authorized users should access information.

Integrity:
Information should not be changed improperly.

Availability:
Systems should remain available to authorized users.
